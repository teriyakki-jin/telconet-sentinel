# Security Policy

## Supported version

Security fixes are applied to the latest commit on the `main` branch.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue.

Use [GitHub's private vulnerability reporting form](https://github.com/teriyakki-jin/telconet-sentinel/security/advisories/new)
to send a private report. Include:

- the affected file, endpoint, or workflow;
- steps to reproduce the issue;
- the potential impact;
- a suggested mitigation, if available.

The maintainer will acknowledge the report within seven days, investigate it, and publish a
fix or status update as appropriate. This repository is a local simulation and does not expose a
production service, but reports about API input handling, workflow permissions, dependency
risks, or unintended host access are still in scope.
